# A Very Big Sum

**HackerRank:** https://www.hackerrank.com/challenges/a-very-big-sum/ ·
**Topic:** Warmup

## Problem
Sum an array of very large integers (beyond 32-bit range).

## Approach
Plain `sum()` — Python integers are arbitrary precision, so no overflow
handling is needed (the challenge targets fixed-width languages).

## Complexity
- Time: **O(n)**
- Space: **O(1)**
