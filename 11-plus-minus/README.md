# Plus Minus

**HackerRank:** https://www.hackerrank.com/challenges/plus-minus/ ·
**Topic:** Warmup

## Problem
Print the fractions of positive, negative, and zero elements (6 decimals).

## Approach
Three generator-expression counts over one pass each, divided by `n`,
formatted with `:.6f`. Prints directly.

## Complexity
- Time: **O(n)**
- Space: **O(1)**
