# Birthday Cake Candles

**HackerRank:** https://www.hackerrank.com/challenges/birthday-cake-candles/ ·
**Topic:** Warmup

## Problem
Count how many candles have the maximum height.

## Approach
`candles.count(max(candles))` — one pass for the max, one for the count.

## Complexity
- Time: **O(n)**
- Space: **O(1)**
